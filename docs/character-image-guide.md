# キャラクター画像表示機能ガイド

[← README.mdに戻る](../README.md)

## 概要
  
このアプリケーションでは、チャット内でキャラクター画像を表示する機能を提供しています。  
画像ページから事前にキャラクター画像を登録しておく事で、URLを使用せずに画像を表示可能です。  
マークダウン記法を使用して、キャラクター・衣装・表情を指定することで、適切な画像を表示できます。  
  
## 機能の特徴

- **マークダウン記法対応**: `![C](:character/キャラクター名/衣装/表情 "Alt")` 形式で画像表示
- **階層構造**: キャラクター → 衣装 → 表情の3層構造で画像を管理
- **一括アップロード**: フォルダ単位での画像一括登録
- **画像管理**: 事前登録による効率的な画像管理
- **エクスポート機能**: 登録した画像のバックアップ

## キャラクター画像の登録方法

### 1. 画像管理ページへのアクセス

1. アプリケーションのメインメニューから「画像管理」を選択
2. 「キャラクター画像」タブをクリック

### 2. キャラクターの作成

1. 「キャラクター追加」ボタンをクリック
2. キャラクター名を入力（例：「アリス」「ボブ」など）
3. キャラクターの説明を入力（任意）
4. 「作成」ボタンをクリック

### 3. 衣装の登録

1. 作成したキャラクターをクリック
2. 「衣装追加」ボタンをクリック
3. 衣装名を入力（例：「制服」「私服」「ドレス」など）
4. 「作成」ボタンをクリック

### 4. 表情画像のアップロード

1. 衣装を選択
2. 「画像追加」ボタンをクリック
3. 表情名を入力（例：「笑顔」「怒り」「悲しみ」など）
4. 画像ファイルを選択（JPG、PNG、WebP対応）
5. 「アップロード」ボタンをクリック

## 一括アップロード機能

### 1. フォルダ一括アップロード

1. キャラクター選択後、「フォルダ一括アップロード」ボタンをクリック
2. フォルダ構造を以下のように準備：
   ```
   アリス/ ← ここを選択
   ├── 私服/
   │   ├── 通常.png
   │   ├── 笑顔.png
   │   └── 驚き.png
   └── 制服/
       ├── 通常.png
       └── 笑顔.png
   ```
3. キャラクター名フォルダを選択してアップロード

### 2. 衣装画像一括アップロード

1. 衣装選択後、「衣装画像一括アップロード」ボタンをクリック
2. 複数の画像ファイルを選択
3. 表情名の自動生成または手動入力
4. 「一括アップロード」を実行

## チャット内での画像表示

### 1. 基本的な記法

```markdown
![C](:character/キャラクター名/衣装/表情 "画像")
```

## 画像管理機能

### 1. 画像の編集

1. 対象画像をクリック
2. 「編集」ボタンをクリック
3. 表情名や画像を変更
4. 変更を保存

### 2. 画像の削除

1. 対象画像をクリック
2. 「削除」ボタンをクリック
3. 削除の確認
4. 画像が削除される

### 3. キャラクター・衣装の管理

1. キャラクター名または衣装名をクリック
2. 「編集」または「削除」を選択
3. 変更を保存

## エクスポート・インポート機能

### 1. 画像のエクスポート

1. 画像管理ページで「エクスポート」ボタンをクリック
2. エクスポート形式を選択（ZIP、JSON）
3. ファイルをダウンロード

### 2. 画像のインポート

1. 「インポート」ボタンをクリック
2. エクスポートファイルを選択
3. インポート設定を確認
4. インポートを実行

### パフォーマンス最適化

- **遅延読み込み**: 画像の遅延読み込み（lazy loading）
- **キャッシュ機能**: 一度読み込んだ画像のキャッシュ
- **画像最適化**: アップロード時の自動画像最適化
- **インデックス**: データベースの複合インデックスによる高速検索

## マークダウン記法の詳細

### 1. 基本構文

```
![C](:character/キャラクター名/衣装名/表情名 "altテキスト")
```

### 2. パラメータ

- **キャラクター名**: 登録済みのキャラクター名
- **衣装名**: 登録済みの衣装名
- **表情名**: 登録済みの表情名
- **altテキスト**: 画像の代替テキスト（任意）

### 4. エラー処理

- キャラクターが見つからない場合：「キャラクターが見つかりません」
- 衣装が見つからない場合：「衣装が見つかりません」
- 表情が見つからない場合：「表情が見つかりません」

## トラブルシューティング

### よくある問題

1. **画像が表示されない**
   - キャラクター名・衣装名・表情名が正確か確認
   - 画像が正しく登録されているか確認
   - マークダウン記法が正しいか確認

2. **画像の読み込みが遅い**
   - 画像サイズが大きすぎないか確認
   - 画像最適化オプションがあるのでそちらを有効にしてアップロードする

3. **一括アップロードが失敗する**
   - フォルダ構造が正しいか確認
   - ファイル名に特殊文字が含まれていないか確認
   - ファイルサイズが制限内か確認
