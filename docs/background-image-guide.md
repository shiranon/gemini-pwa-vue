# 背景画像変更機能ガイド

## 概要

このアプリケーションでは、AIとのチャット中に背景画像を動的に変更する機能を提供しています。  
Function Calling機能を使用して、AIが物語のシーンや雰囲気に応じて適切な背景画像を自動選択できます。  

## 機能の特徴

- **Function Calling対応**: AIが自動的に背景を選択・変更
- **一時的な背景変更**: チャット中のみ背景を変更（永続的ではない）
- **優先順位制御**: Function Calling > チャット設定の順で背景が決定
- **画像管理**: 事前に背景画像をカテゴリー別に登録可能

## 背景画像の登録方法

### 1. 画像管理ページへのアクセス

1. アプリケーションのメインメニューから「画像管理」を選択
2. 「背景画像」タブをクリック

### 2. カテゴリーの作成

1. 「カテゴリー追加」ボタンをクリック
2. カテゴリー名を入力（例：「街並み」「自然」「室内」など）
3. カテゴリーの説明を入力（任意）
4. 「作成」ボタンをクリック

### 3. 背景画像のアップロード

1. 作成したカテゴリーをクリック
2. 「画像追加」ボタンをクリック
3. 画像ファイルを選択（JPG、PNG、WebP対応）
4. 画像名を入力（例：「朝の駅」「夕暮れの森」など）
5. 「アップロード」ボタンをクリック

### 4. 複数画像の一括アップロード

1. カテゴリー選択後、「一括アップロード」ボタンをクリック
2. 複数の画像ファイルを選択
3. 画像名の自動生成または手動入力
4. 「一括アップロード」を実行

## Function Callingでの背景変更

### 1. Function Callingの有効化

1. 設定ページで「Function Calling」を有効にする
2. 「背景画像管理」ツールを選択
3. 設定を保存

### 2. AIとの会話での背景変更

AIとの会話中に、以下のような指示を出すことで背景が自動変更されます：

```
「朝の駅のシーンに背景を変更して」
「夕暮れの森の雰囲気に背景を設定して」
「雨の街の背景にして」
```

### 3. 背景変更の仕組み

1. AIが会話の文脈から適切な背景を判断
2. 登録済みの背景画像から最適なものを選択
3. 一時的に背景を変更（チャット終了まで有効）
4. チャット終了後は元の背景に戻る

## チャット設定での背景変更

### 1. チャット画面での背景変更

1. チャット画面で「設定」ボタンをクリック
2. 「背景画像」セクションを選択
3. 登録済みの背景画像から選択
4. 背景が即座に変更される

### 2. 基本構文

```
(!BG :background/カテゴリ名/シチュエーション名)
```

### 3. 優先順位について

- **Function Calling**: AIが自動選択した背景（優先）  
- **チャット設定**: 手動で設定した背景
## 背景画像の管理

### 1. 画像の編集

1. 画像管理ページで対象画像をクリック
2. 「編集」ボタンをクリック
3. 画像名やカテゴリーを変更
4. 変更を保存

### 2. 画像の削除

1. 対象画像をクリック
2. 「削除」ボタンをクリック
3. 削除の確認
4. 画像が削除される

### 3. カテゴリーの管理

1. カテゴリー名をクリック
2. 「編集」または「削除」を選択
3. 変更を保存

## トラブルシューティング

### よくある問題

1. **背景が変更されない**  
   - Function Callingが有効になっているか確認  
   - 背景画像が正しく登録されているか確認  
   - ブラウザのキャッシュをクリア

2. **画像が表示されない**  
   - 画像ファイルの形式を確認（JPG、PNG、WebP対応）  
   - ファイルサイズが大きすぎないか確認  
   - ブラウザの開発者ツールでエラーを確認

3. **Function Callingが動作しない**  
   - AIモデルがFunction Callingに対応しているか確認  
   - 設定でFunction Callingツールが選択されているか確認  
   - 会話の文脈が背景変更に適しているか確認

### パフォーマンスの最適化

- 画像サイズは適切に調整（推奨：1920x1080以下）  
- 画像最適化設定を使用する  
- 不要な背景画像は定期的に削除  
- ブラウザのストレージ容量を確認
